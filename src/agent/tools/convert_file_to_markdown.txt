将 PDF、Word、Excel 或 HTML 文件转换为 Markdown 文件，便于后续读取、检索、分析或基于文档内容开发。

适用场景：
- 当用户要求阅读、总结、分析或依据工作区内的 `.pdf`、`.docx`、`.xlsx`、`.xls`、`.html`、`.htm` 文件开展工作时，优先使用本工具先转换为 Markdown。
- 当文档内容较长、结构复杂，直接处理二进制/办公文档不方便时，使用本工具生成可读取的 `.md` 文件。
- 转换成功后，如需继续分析完整内容，应读取生成的 Markdown 文件；工具返回内容只作为预览。

不适用场景：
- 源文件已经是 Markdown、纯文本、代码文件或其他可直接读取的文本文件时，直接使用读取工具。
- 远程 URL 内容应使用网页获取工具，不使用本工具。
- 本工具不用于图片 OCR、音视频转写或非支持格式转换。

参数规则：
- filePath 必须是工作区内已存在文件的绝对路径。
- outputPath 可选；不传时默认写到源文件同目录、同名但后缀为 `.md` 的文件。
- outputPath 如传入，必须是工作区内绝对路径，并且必须以 `.md` 结尾。
- 目标 Markdown 文件已存在时工具会失败，不会覆盖。
